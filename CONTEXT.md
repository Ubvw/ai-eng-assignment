# Recipe enhancement

This context covers how feedback from a recipe page informs changes to the source recipe.

## Language

**Most helpful review**:
The review the source recipe page surfaces as its most helpful positive review.

**Featured tweak**:
A review showcased by the source recipe page as a potential recipe improvement.

**Selected review**:
The first eligible review in helpful-vote order that yields an applicable modification. It is the source of the recipe enhancement's modifications.

**Source step**:
An instruction entry supplied by the recipe source. A source step can describe several actions.

**Review evidence**:
A verbatim passage from a specific review that supports a proposed recipe modification.

**Meaningful modification**:
A change described in a review with a plausible benefit for the recipe. The benefit can be reported by the reviewer or inferred, with helpful votes as one signal.
